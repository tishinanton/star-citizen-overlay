# Download landing page

- Scope and mode: Public GitHub Pages landing page in Persuade mode.
- Audience and job: Windows-based Star Citizen players deciding whether Rockfall will make mining scans, blueprint planning, and faction progression easier to understand during play.
- Primary action: Download the latest Windows installer. Secondary actions are reading release notes and viewing the source repository.
- Proof: A working visual explanation of the deterministic cluster-signature readout, followed by truthful mining, blueprint, faction, shortcut, update, local-data, and optional phone-control capabilities.
- Direction: Extend the existing rugged blue-black and scanner-cyan cockpit instrument language. Use a continuous telemetry route rather than a generic hero-and-card stack.
- Memorable moment: A live-looking Agricium scan turns one verified base signature into the one-through-eight-rock cluster sequence while the download action remains visible.
- Constraints: Static, fast, accessible, responsive, relative-path safe for project Pages, no invented telemetry or live-game integration claims, and no dependency on unauthenticated GitHub API requests at runtime.
- Unresolved decisions: None.
