MINING / SIGNATURE ARRAY

Identify the cluster, not just the material.

Select up to four targets, compare each base electromagnetic signature, and see deterministic cluster values from one through eight rocks. The overlay keeps the answer visible while game input stays untouched.

  • Search by material and mining method
  • Rank high-quality mining sites for the selected ore
  • Correct a local signature and reset it at any time
  • Compact, spotlight, opacity, size, and position controls

BLUEPRINTS / CRAFTING WORKBENCH

Trace every output back to what unlocks it.

Search extracted blueprint outputs, inspect resource requirements and craft time, then follow the missions, providers, systems, and reputation gates that lead to the reward.

  • Filter by category, collection, and access state
  • Separate owned from still-obtainable blueprints
  • Scan Game.log receipts without guessing ambiguous names
  • Keep manual ownership marks explicit and reversible

FACTIONS / REPUTATION DIRECTORY

See what a standing actually requires.

  • Search factions, tracks, profile text, and rank names
  • Filter lawful and unlawful organizations
  • Compare minimum thresholds and reputation drift
  • Read perks and gate flags without relying on color

Set it once. Keep flying.

Rockfall stays available through the tray, global shortcuts, and optional local-network controls while Star Citizen keeps focus.

  1. 1

    Point Rockfall at the game.

    Common LIVE and PTU installs are detected automatically, or you can select a custom Data.p4k archive.

  2. 2

    Choose the reference you need.

    Pin mining targets, inspect a blueprint, or compare a faction track from the control console.

  3. 3

    Return to the cockpit.

    Drag the cyan overlay header into place. Its body remains non-focusable and click-through.
